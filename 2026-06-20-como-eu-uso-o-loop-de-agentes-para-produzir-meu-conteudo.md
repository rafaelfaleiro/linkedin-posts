# Como eu uso o loop de agentes para produzir meu conteúdo.

Como eu uso o loop de agentes para produzir meu conteúdo.

A maior parte das pessoas ainda produz conteúdo com IA da pior forma: conversando com o chat.

Escreve um prompt, recebe uma primeira versão, acha o texto meio genérico, pede para melhorar, recebe outra versão parecida e termina gastando energia tentando explicar o próprio gosto para a máquina.

Eu comecei a usar de outro jeito.

Hoje eu mando o briefing pelo WhatsApp ou pelo Telegram. Pode ser texto ou um áudio curto explicativo. Às vezes, também peço para o agente pesquisar opiniões de outros especialista.

Esse meu fluxo roda no OpenClaw. A mesma lógica poderia ser montada no n8n ou em outra ferramenta agêntica.

Tenho dois agentes que rodam em loop.

O primeiro agente atua como editor. Ele recebe a ideia, entende o contexto e escreve usando uma skill com meu tom de voz, meu estilo de escrita, minhas preferências de estrutura e sem os vícios de IA que eu quero evitar.

Só que a primeira versão não chega direto em mim.

Antes, ela passa por outro agente, responsável pela revisão. Esse revisor procura problemas que normalmente eu teria que caçar manualmente: abertura fraca, cadência artificial, frases de IA, excesso de explicação…

Quando o texto não passa, o revisor aponta o trecho que precisa melhorar, explica o problema e devolve uma orientação específica para o editor.

O editor ajusta. O revisor confere de novo.

O ciclo continua até o post ficar bom o suficiente para chegar em mim pronto para a publicação.

A ideia inicial continua sendo minha. A decisão final também.

O que muda é o caminho entre uma anotação crua e um texto publicável.

Ficou muito mais produtivo para mim.

Para receber os detalhes comenta “fluxo” e eu te mando o passo a passo.
