# A Palantir Technologies vale US$ 300 bilhões porque entendeu uma coisa sobre o cliente que muita empresa ignora.

A Palantir Technologies vale US$ 300 bilhões porque entendeu uma coisa sobre o cliente que muita empresa ignora.

É no uso do cliente que o produto mostra suas limitações.

Para lidar com isso, a Palantir coloca engenheiros dentro da operação do cliente para ver como o software se comporta no dia a dia. São os Forward Deployed Engineers.

Os engenheiros não estão lá apenas para ouvir pedido ou apagar incêndio.

Eles observam onde a rotina trava, onde o time improvisa, onde nasce uma planilha paralela e quais tarefas ainda dependem de trabalho manual.

Esse aprendizado volta para o produto quando o mesmo padrão aparece em mais de uma conta.

A dor que parecia exclusiva de um cliente vira padrão de implantação.

Muita empresa quer aumentar LTV com reunião de acompanhamento, pesquisa de satisfação mas deixa falhas na hora de atender o trabalho crítico do cliente.

LTV cresce quando o produto reduz retrabalho, elimina improvisos e absorve exceções que antes obrigavam o cliente a criar caminhos paralelos.

Na Palantir, a proximidade com o cliente funciona porque o que aparece no campo volta para o produto.

Com esse ciclo, o fornecedor passa a resolver partes mais críticas da rotina do cliente e ganha motivo real para permanecer na conta.
